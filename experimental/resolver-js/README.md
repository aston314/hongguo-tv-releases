# 播放解析 JS 实验文件

本目录用于独立测试包的本地 JS 更新验证，正式应用尚未启用。

- `manifest.json`：Ed25519 签名清单，包含启用状态、控制版本、模块版本、兼容要求、下载地址、文件大小和 SHA256。
- `resolver.js`：已验证的本地解析脚本；请求和解析在用户设备执行，本仓库只提供静态文件。

客户端下载清单与脚本时使用既有 GitHub 代理和直连回退。清单有实验有效期，已验签并保存的脚本可以离线继续使用。

更新时先验证脚本并重新生成签名清单，再一起提交。修改下载地址也必须重新签名；控制版本必须递增，同一模块版本不能对应不同脚本内容。签名私钥不存放在本仓库、客户端或普通发布文件中。

本目录独立于源码仓库与正式 APK 更新清单；源码仓库调整可见性不会改变这里的下载地址。
