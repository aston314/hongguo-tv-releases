# 播放解析自动修复

本目录提供支持“自动修复播放解析”功能的应用使用的静态更新文件。应用内默认关闭，用户可在设置中开启；不需要填写地址或另设服务器。

- `manifest.json` 是 Ed25519 签名清单，包含启用状态、递增控制版本、有效期和模块兼容要求。
- `modules/<SHA256>.js` 为不可变的解析规则文件。注册、请求签名及模型解析在设备本地执行，媒体播放仍由应用原播放器负责。

应用通过既有 GitHub 代理与直连回退下载，先验签、校验大小及 SHA256、自检，再切换之后的取源请求。下载失败保留已有解析；远程停用或脚本故障时保留内置解析。

规则由源码仓库的“Publish signed playback resolver rules”工作流生成并签名。私钥仅存在于该仓库的加密 Secret 中，不随文件分发。控制版本必须递增，改动脚本必须使用新的模块版本，保留旧模块文件以支持离线缓存和回滚。

这是解析规则分发渠道，不是 APK 更新，也不提供服务端视频解析。实验测试文件继续放在 `experimental/resolver-js/`，两条渠道的签名密钥独立。
